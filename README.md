P.1 — Barbearia Black

Projeto de um site de agendamento para uma barbearia, feito para praticar HTML, CSS e JavaScript.

A ideia foi criar algo simples, mas que tivesse algumas funções além de uma página comum.

Funcionalidades

* Página inicial da barbearia
* Área com os serviços disponíveis
* Formulário para marcar horário
* Escolha do barbeiro, data e horário
* Campo para informar como o cliente quer o corte
* Detalhes como degradê, laterais, tamanho em cima, barba e sobrancelha
* Salvamento dos agendamentos no navegador
* Opção de cancelar um agendamento
* Geração da mensagem para enviar pelo WhatsApp
* Layout adaptado para celular e computador

Tecnologias usadas

* HTML
* CSS
* JavaScript
* LocalStorage

## Objetivo

Esse é o meu primeiro projeto dessa sequência e foi feito principalmente para colocar em prática o que estou aprendendo sobre desenvolvimento web.

Pretendo continuar fazendo outros projetos para melhorar minhas habilidades e testar novas ideias.
